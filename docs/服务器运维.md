# 服务器运维（阿里云 ECS）

> 这台机器是「让所有人能用」的公网入口。前端和后端都在这上面，Nginx 同时托管静态页并把 `/api` 反代到 Node。

## 一、访问地址

| 入口 | 地址 | 说明 |
|---|---|---|
| **公网（推荐给评委/老师）** | http://120.78.120.161/ | 前端 + 真模型，同一域名，无跨域/混合内容问题 |
| 备用（静态、离线兜底） | https://liaohc-42.github.io/sports-fuel-agent/ | 无后端，自动用本地规则引擎 |

- 服务器：Alibaba Cloud Linux 3（x86_64），Node 20.18.0（`/usr/local/node`），nginx 1.24
- 代码目录：`/var/www/sports-fuel/`（`frontend/` + `backend/`）
- 后端进程：systemd 服务 `sports-fuel`，监听 `127.0.0.1:3000`（仅本机，外部只能经 Nginx 的 80 端口）

## 二、日常命令

```bash
# 状态
systemctl status sports-fuel nginx --no-pager
curl -s http://127.0.0.1/api/health

# 重启后端 / 重载 nginx
systemctl restart sports-fuel
nginx -t && systemctl reload nginx

# 看后端日志（实时）
journalctl -u sports-fuel -f
```

## 三、填写 / 更换大模型 Key

```bash
sed -i 's/^GLM_API_KEY=.*/GLM_API_KEY=你的Key/' /var/www/sports-fuel/backend/.env
systemctl restart sports-fuel
curl -s http://127.0.0.1/api/health
```

期望返回 `"agent":true,"provider":"glm"`。

> DeepSeek 同理：`sed -i 's/^DEEPSEEK_API_KEY=.*/DEEPSEEK_API_KEY=sk-xxx/'`，并在 `.env` 里设 `PROVIDER=deepseek`。

## 四、更新代码

本地打包（排除 `node_modules` 和 `.env`）→ 上传 → 解压覆盖 → 重启：

```powershell
tar --exclude='backend/node_modules' --exclude='backend/.env' -czf bundle.tgz -C sports-fuel-agent frontend backend
scp bundle.tgz root@120.78.120.161:/tmp/
```

```bash
tar -xzf /tmp/bundle.tgz -C /var/www/sports-fuel
cd /var/www/sports-fuel/backend && npm install --omit=dev --registry=https://registry.npmmirror.com
systemctl restart sports-fuel
```
