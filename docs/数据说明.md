# 数据说明

## 1. 食堂菜单与价格

- **来源**：《中山大学食堂菜单价格明细表.xlsx》（共 3 个工作表：菜品价格明细、价格档位汇总、食堂价格覆盖）。
- **规模**：647 道菜，覆盖 **5 个校区**（广州南校园、广州北校园、广州东校园、珠海校区、深圳校区）+ "全校区同步"时令上新，共 46 个食堂。
- **价格口径**：
  - `有标价`：直接用原表价格（如"水煮肉片 12 元"）；
  - `无标价(自选/称重/当日浮动)`：占约 84%，前端显示"参考价（估）"，按**分类默认价**估算（主食≈4–10 元、热菜≈14 元、烧腊≈15 元、蔬菜≈4 元、糖水≈8 元、套餐≈20 元等）；
  - 区间价（如"11-14 元"）：显示为区间。
- **更新机制**：数据由 `scripts/xlsx_to_canteen.py` 从 Excel 自动生成 `frontend/data/canteen.js` 与 `backend/data/canteen.json`；也支持 `POST /api/canteen` 运行态更新，弥补食堂当日菜单更新慢的缺点。
- **来源追溯**：原表每条标注了数据出处（如"中大饮食公众号""松涛园实测""食在中大·珠海篇"等），已保留在数据中。

## 2. 营养数据

- **优先**：`frontend/data/nutrition.js` 内置常见食堂菜品营养库，数值参考《中国食物成分表（标准版 第6版）》常见份量换算（标记 `src:'库'`）。
- **估算**：未收录菜品按"菜名关键词 → 分类 → 分类默认营养"兜底（标记 `src:'估'`），前端显示为**「估算值」**。
- **单位**：均为"每份（常见食堂份量）"：kcal、蛋白质 g、碳水 g、脂肪 g。

## 3. 运动热量

- 公式：`kcal = MET × 3.5 × 体重(kg) / 200 × 分钟`。
- MET 参考《Compendium of Physical Activities (2011)》。
- 基础代谢 BMR 用 Mifflin-St Jeor 公式；建议摄入在 BMR×1.3（日常活动）+ 运动消耗基础上，按目标加/减（增肌 +300、减脂 -400、维持 ±0）。

## 4. 体测评分

- **依据**：《国家学生体质健康标准（2014 年修订）》大学组 **「单项指标评分表」** 原表录入（不是估算）。
- **分组**：内置「大一、大二」和「大三、大四」**两套**分组表（各 20 档），页面「年级」下拉自动切换对应表；BMI 表两组通用。
- **来源**（公开可查，三处交叉核对，数值一致）：
  - 哈尔滨工程大学体育部《体质测试标准》：完整的男女 × 大一/大二、大三/大四 分组表；
  - 青岛大学体育学院《50 米跑测试动作规范及评分标准》：50 米跑分组表；
  - 四川农业大学体育学院《〈国家学生体质健康标准〉评分表（2014年修订）》：男生各项。
- **权重**：BMI 15% / 肺活量 15% / 50米跑 20% / 坐位体前屈 10% / 立定跳远 10% / 引体向上（男）·1分钟仰卧起坐（女）10% / 1000米（男）·800米（女）20%。
- **算分方式**：每个单项按原表线性插值得到单项得分，再按权重加权得到总分；**全程不用大模型算分**，避免幻觉。
- **关键口径（已核对原表）**：
  - 引体向上（男）：大一/大二 0 个 = 0 分、5 个 = 10 分、10 个 = **60 分（及格线）**、19 个 = 100 分；大三/大四 6 个 = 10 分、11 个 = **60 分**、20 个 = 100 分；
  - 1 分钟仰卧起坐（女）：大一/大二 16 个 = 10 分、26 个 = **60 分**、56 个 = 100 分；大三/大四 17 个 = 10 分、27 个 = **60 分**、57 个 = 100 分；
  - 1000 米（男）：大一/大二 4'32" = 60 分、3'17" = 100 分；大三/大四 4'30" = 60 分、3'15" = 100 分；
  - 800 米（女）：大一/大二 4'34" = 60 分、3'18" = 100 分；大三/大四 4'32" = 60 分、3'16" = 100 分。
- ⚠️ 各校可能执行不同版本或补测口径，**最终以学校执行为准**；如需替换，改 `frontend/js/app.js` 中的 `FT` 对象即可。

## 5. 估算的局限（务必在答辩中主动说明）

- 无标价菜的"参考价"是分类均值，**不等于实际价格**；
- 营养"估算值"受做法（油量、份量）影响大，只能作为参考；
- 热量缺口是"估算"而非"精确测量"，鼓励用户按体重变化反馈调整。
- 体测评分表按 2014 版大学组录入，已内置大一/大二、大三/大四两套分组表；若学校补测口径不同（如加分项），以学校执行为准。

> 这些局限我们用「标注估算值 + 可手动更新 + 大模型兜底」三件事来缓解，属于数据源本身的客观情况，如实说明反而更可信。
