# 使用说明（评委/用户快速上手）

## 打开页面

- **线上**：`https://<用户名>.github.io/<仓库名>/`（GitHub Pages 自动部署）
- **本地**：`frontend/` 目录用任意静态服务器打开 `index.html`（如 `npx serve .`）

页面顶栏右侧会显示当前模式：**「已连接 Agent」**（后端+Key 就绪）或 **「本地引擎(免费)」**（离线兜底）。两种模式下核心功能完全一致。

---

## 一、练完吃啥（主项目）

### 第一步：设置档案（可选，建议先做）
点右上角 **「👤 我的档案」**，填性别/年龄/身高/体重/默认目标，保存。这决定热量和营养计算。

### 第二步：选目标
在"你的目标"里点 **增肌 / 减脂 / 维持**。

### 第三步：记录今天练了什么
1. 选运动项目（跑步 / 徒步 / 游泳 / 力量 / 球类 / 骑行 / 跳绳 / 瑜伽）。
   - 力量和球类会展开**子分支**（上肢/下肢/核心/全身；篮球/足球/羽毛球…）。
2. **时长**：拖动数轴（分度值 5 分钟）。
3. **强度**：点轻松/正常/较快，下方小字会显示对应的**参考标准**（如跑步"正常=配速 5'00"~7'00"）。
4. 卡片下方即时显示：**运动消耗、基础代谢、建议摄入、今日热量缺口**。

### 第四步：勾选今天食堂的菜
1. **校区 → 食堂 → 窗口/楼层** 三级选择。
2. 在列表里勾选菜品（可搜索），带价格；无标价菜显示"参考价"。
3. 也可以**手动输入**列表里没有的菜（营养按常识估算）。

### 第五步：设置这顿的约束
- **预算**：拖动数轴（0–30 元，分度 1 元），或点"不限"/输入自定义金额。
- **路上时间**：拖动数轴（0–30 分钟，分度 1 分钟），或点"不赶时间"/输入自定义。

### 第六步：生成搭配
点 **「✨ 生成我的搭配」**，得到：
- 两套搭配（首选 + 备选）；
- 每道菜标注 **推荐 / 适量 / 少吃**；
- 蛋白质/碳水/脂肪 **占比条** + 三大营养素克数 + 预估价格；
- **替代建议**（如"白米饭换玉米"）。

点 **「💾 记下这一餐」** 可保存到记录。

## 二、记录

- **修改今日方案**：增删菜品后点"让 AI 给我接下来的建议"，得到未来 1–2 餐的调整建议。
- **饮食花销统计**：查看累计/平均/预估月花销；输入下月预算，AI 给省钱建议。
- **最近运动**：切 **本周/本月/今年**，直方图展示运动时长与热量，点"AI 运动建议"获取调整建议。

---

## 三、原理与数据

- **智能健身教练**：直接提问（如"练完腿很酸吃什么？"），默认走本地规则引擎，配置后端后回答更自然。
- **参考文献**：列出《中国居民膳食指南(2022)》等依据，增强可信度。
- **开发者后端**：展示 API Key 配置状态与说明。

## 四、体测急救站（副项目）

1. 输入：性别、年级、耐力跑项目与成绩（格式 `4:35`）、引体/仰卧起坐个数、距体测天数、每周可练天数、伤病/场地限制。
2. 点 **「生成诊断」**：
   - 得到各项目**得分**与**提分性价比**结论（先练哪项）；
   - **未来 N 天计划**（每天 15–25 分钟，考前 3 天自动减量）；
   - **今日训练**（可点"▶ 计时"倒计时）；
   - **配速器**（每 200 米报时，不依赖 GPS）；
   - **打卡调载**：点"太累/疼痛/没时间"，系统自动降载或换项。

## 常见问题

- **页面没反应？** 确认浏览器允许 JavaScript；数据存在 localStorage，清空浏览器数据会清掉记录。
- **想用真实大模型？** 见 [README](../README.md) 的「🔑 Agent API Key 配置」。
- **数据准不准？** 见 [数据说明](数据说明.md)。
