# 后端上线清单（让评委/老师直接能用真模型）

> 目标：任何人（包括国内网络）打开 `https://liaohc-42.github.io/sports-fuel-agent/`
> 就能用上真模型（AI 点评 / 教练问答 / 图片识别），而不是只剩本地规则引擎。
>
> 核心只有一句：**一个国内可达的入口 + 一个模型 Key**。钱可以是 0 元。

---

## 一、最小清单

| # | 需要什么 | 怎么拿 | 谁做 | 耗时 | 花钱 |
|---|---|---|---|---|---|
| ① | 智谱 GLM API Key | open.bigmodel.cn 注册 → API Keys（GLM-4-Flash 免费） | 你 | 5 分钟 | 0 |
| ② | 国内可达的后端入口 | 见第二节三选一 | 你 | 10–60 分钟 | 0 |
| ③ | 把入口写进前端 | `frontend/js/api.js` 的 `API_BASES[0]` | 我 / 你 | 5 分钟 | 0 |
| ④ | 验收 | `GET <入口>/api/health` 返回 `provider: "glm"` | 我 | 2 分钟 | 0 |

> 只有 ② 选「云函数」时需要实名认证；选「内网穿透」不需要。

---

## 二、入口三选一

### A. 阿里云函数计算 FC（最稳，推荐）

1. 控制台 → 函数计算 FC → 创建函数 → **Node.js 18** → 触发器选 **HTTP**。
2. 代码包上传整个 `backend/` 目录（含 `node_modules`，或在控制台「在线构建」装依赖）。
3. 入口文件改成：

   ```js
   // backend/index.js
   const serverless = require('serverless-http');
   const app = require('./server');   // server.js 里已有 module.exports = app
   module.exports.handler = serverless(app);
   ```

   依赖补一个：`npm i serverless-http`

4. 环境变量：`GLM_API_KEY=<你的key>`、`PROVIDER=glm`。
5. 记下默认域名：`https://xxxx.cn-hangzhou.fcapp.run`。
6. 浏览器打开 `<域名>/api/health`，看到 `{"agent":true,"provider":"glm",...}` 即成功。

> 腾讯云 SCF + API 网关同理，步骤几乎一致。

### B. 内网穿透（最快，10 分钟，无需实名）

1. 本机：`cd backend && npm start`（打印 `provider = glm`）。
2. 装 `cpolar` 或 `ngrok`，执行 `cpolar http 3000` / `ngrok http 3000`。
3. 拿到形如 `https://xxxx.cpolar.cn` 的 https 地址。
4. 同上填进 `API_BASES[0]`。

⚠️ 代价：**电脑必须一直开着**；免费版域名会变、有限速。适合答辩当天，不适合长期。

### C. 云服务器 / 学生机（最省事，0 代码改动）

1. `npm start`（建议配 pm2 守护）。
2. 安全组放行 3000 端口，直接用 `http://<公网IP>:3000`。
3. **不要绑自己的域名**——绑域名需要 ICP 备案（个人 1–2 周），来不及。

---

## 三、为什么不用备案

- 云函数的**平台默认域名**（`*.fcapp.run` / SCF 默认域名）由平台备案，使用者无需备案；
- 只有**绑定自己的域名**才需要 ICP 备案。
- 所以路径选 A 或 B，就绕开了备案。

---

## 四、公开上线前必做（安全 / 成本）

现在 `backend/server.js` 是「全放行」状态，公开后等于公开 Key：

| 项 | 现状 | 应改为 |
|---|---|---|
| CORS | `app.use(cors())` 全放行 | 只允许 `https://liaohc-42.github.io` |
| 限流 | 无 | 按 IP 每分钟 10 次左右 |
| 请求体 | `limit: '1mb'` | 100KB 足够（视觉接口另算） |
| Key 存放 | 环境变量 ✓ | 保持，永不进 git |
| 预算 | 无 | 平台用量告警 + 模型额度上限 |

## 五、验收清单
